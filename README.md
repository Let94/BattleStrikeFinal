# BattleStrikeFinal

FPS shooter project designed for Unity.

## Included
- FPS player movement and mouse look
- Sprint and jump
- Hitscan weapon system
- Magazine, ammo and reload system
- Health and damage system
- Basic crosshair

## Unity setup
1. Clone/download this repository.
2. Open the repository folder from Unity Hub.
3. Use a recent Unity LTS version.
4. Add the scripts from `Assets/Scripts` to the corresponding GameObjects.

The project is being built progressively with game modes, Chill mini-games, rewards, skins, UI and other systems.
